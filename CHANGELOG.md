# Changelog

Releases are named "True Intel V&lt;n&gt;" (tag `v<n>`). Each section is that release's notes.

## V1 (2026-10-15)

- The Armory's armor passive descriptions show the real numbers:
  - GUNSLINGER: sidearm reload speed +60%. The game says 40%, but the passive applies 60%.
  - Armor rating: EXTRA PADDING +50; CONCUSSIVE PADDING, REINFORCED +30; UNFLINCHING, SUPPLEMENTAL ADRENALINE and BLUNT-FORCE MITIGATION +25. This is part of the armor rating the Armory shows.
  - Weapon ergonomics: PEAK PHYSIQUE +30, TRUE GRIT +20 (a weapon's ergonomics tops out at 100).
  - SUPPLEMENTAL ADRENALINE: 2% stamina back for every 1% of health lost.
  - ROCK-SOLID and BLUNT-FORCE MITIGATION: 30% less knockdown force.
  - OXYGENATOR: 10% faster jogging and sprinting (walking is unchanged).
- The other reload, ammo and sidearm lines already match what their passives apply. If a game update makes one differ, its real number shows.
- Every number is read from the game when the lines are made.
- Display only: nothing the game uses changes, so it is safe in any lobby.
- In every game language.
